# Supply-Chain-Working-Capital-Inventory-Optimization-Engine
**Objective: Audit a $296M inventory portfolio to eliminate excess stock holding costs while maintaining a 95% service level.**
2. Tech Stack Used
Database & Querying: PostgreSQL, SQLAlchemy, Advanced SQL (Window Functions, CTEs, Pareto ABC Analysis).

Optimization & Modeling: Python (pandas, numpy, scipy).

Domain Focus: Supply Chain Finance, Working Capital Management, EOQ Modeling.

3. Key Technical Highlights (What Recruiters Look For)
Relational Database Management: Programmatically ingested 500+ SKU records into a local PostgreSQL database instance.

Advanced SQL Analytics: Developed multi-layered Common Table Expressions (CTEs) combined with window functions (SUM() OVER) to execute Pareto (ABC) classification across inventory tiers.

Operations Research: Implemented mathematical EOQ and dynamic safety stock equations to optimize reorder points and order quantities.

Financial Impact Translation: Converted operational efficiency metrics directly into Balance Sheet liquidity (Working Capital Freed) and Income Statement savings (Carrying Costs).
